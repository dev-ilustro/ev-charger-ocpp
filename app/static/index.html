คำสั่ง

ควบคุมสถานะ Availability

ใช้บังคับปลด/ล็อคเครื่องด้วยมือ เผื่อระบบล็อคอัตโนมัติ (ล็อคจนกว่าจะแตะบัตร) ค้างหรือทำงานผิดปกติ

ป้องกันเครื่องปลดล็อคหัวชาร์จเองอัตโนมัติ

รถ EV บางรุ่นสั่งให้เครื่องชาร์จปลดล็อคหัวชาร์จเองทันทีที่ชาร์จเสร็จ โดยไม่รอคำสั่งจาก Server ทำให้ระบบ "ต้องชำระเงินก่อนปลดล็อค" ถูกข้ามได้ ปุ่มนี้จะสั่งปิด configuration key มาตรฐาน OCPP UnlockConnectorOnEVSideDisconnect (ตั้งเป็น false) เพื่อให้เครื่องรอคำสั่งปลดล็อคจาก Server เท่านั้น — ใช้ได้เฉพาะเครื่องที่รองรับ key นี้ (บางรุ่นอาจไม่มีให้ตั้ง)

รีสตาร์ทเครื่อง

Soft = restart เฉพาะ software ของเครื่อง (ตัดการชาร์จที่ทำอยู่ก่อนแล้วค่อย restart)
Hard (Reboot) = รีบูตตัวเครื่องทั้งหมด เหมือนถอดปลั๊กแล้วเสียบใหม่ ใช้เมื่อเครื่องค้าง/ไม่ตอบสนอง
